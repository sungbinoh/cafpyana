# Good-beam lists

Beam quality is a per-spill selection, so the primary list is per event: `good_beam_events.csv.gz` holds
(run, subrun, evt) of every BNB-triggered event (`spill` tree of `data/beamQ`) whose spill passes
TOR860, TOR875 > 1e11; 173 <= THCURR <= 175 kA; 0.98 < FOM_best <= 1 (NaN fails), as in SBN-doc-49735-v1.
Match to CAF events with `rec.hdr.run`, `rec.hdr.subrun`, `rec.hdr.evt` (ICARUS `evt` repeats across subruns; `subrun` is 1 throughout in SBND).
Events absent from the `spill` tree have no beam information and count as not good.
The run lists are secondary: a run is listed if it has any good-beam POT (POT = `tor_used` of all `bnbinfo` spills).

Files in `output/beam_quality/<ds>/good_beam/`; generated by `code/make_beam_lists.py`.
